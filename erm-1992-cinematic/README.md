# ERM 1992 — Cinematic financial documentary

8 seconds, 1920x1080, 30fps, 240 frames. Conceptual ERM exchange-rate mechanism visualization. FRF, DEM, GBP ornamental SVG note representations, followed by an illustrative line that stays inside unlabeled upper/lower gold boundaries, and the user-specified reference `1 GBP = 2,95 DEM`.

**Accuracy:** Banknotes are original stylized SVG representations, **not reproductions of authentic historical banknotes**. The chart is schematic, not actual 1992 market data. The central reference is illustrative, not a claim about the historical rate. No historical numeric band values are invented. No external assets required.

Run `bun i`, `bun run build`, `bun run render`. Output `out/ERM1992.mp4`, artifact `ERM1992-MP4`.
