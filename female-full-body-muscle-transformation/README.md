# FemaleMuscleTransformation

Independent 6-second vertical 1080×1920 30fps full-body female silhouette muscle growth. Procedural SVG: separately deformable arms, shoulders, core, thighs and calves; progressive localized enlargement, glow, particle energy, sweep and final flex. No external images, 3D, text, audio or split screen.

Commands: `bun i`, `bun run build`, `bun run render`.

Output: `out/FemaleMuscleTransformation.mp4`. GitHub artifact: `FemaleMuscleTransformation-MP4`.
