# CoachingAdMotion

6 seconds / 180 frames / 1080×1920 / 30 FPS / H.264. Uses the ORIGINAL Facebook screen recording as an OffthreadVideo background and overlays a fictional sponsored coaching ad. The ad is a visual simulation, not a published Facebook advertisement.

**Important:** Download the complete ZIP provided in ChatGPT and upload its `public/facebook-capture.mp4` to this GitHub project. GitHub Actions cannot render without that original source video. The supplied ZIP already contains the video and all source files.

Commands: `bun i`, `bun run build`, `bun run dev`, `bun run render`. Output: `out/CoachingAdMotion.mp4`. Artifact: `CoachingAdMotion-MP4`.
