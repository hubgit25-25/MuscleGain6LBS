# Ce n'est pas un manque d'infos — Remotion

Kinetic typography vertical, fond blanc, Helvetica/Arial Black, noir et rouge.

## Specs
- 1080 × 1920 (9:16)
- 30 FPS
- 180 frames / 6 secondes
- Composition : `CeNestPasInfos`
- Export : MP4 H.264

## Installation

```bash
cd projects/ce-nest-pas-infos
bun install
```

## Prévisualiser

```bash
bun run start
```

## Rendre le MP4

```bash
bun run render
```

Le fichier sera créé dans `out/ce-nest-pas-infos.mp4`.

La police utilise Helvetica Neue si elle est disponible sur le système, avec Arial en solution de repli.
