# FacebookCoachingAd

Composition Remotion React TypeScript, 1080×1920, 30 FPS, 180 frames / 6 s. Mockup fictif de publication sponsorisée Facebook pour coaching fitness, sans données personnelles ni faux témoignages. UI blanche, carte fitness noire/rouge, typographie blanche et jaune, apparition spring, zoom, textes mot par mot, bouton « En savoir plus ». Illustration vectorielle générique intégrée, sans média externe requis.

Le texte original exact est conservé dans `src/copy.ts` (propriété `full`). Les deux scènes le reprennent en capitales, réparti en deux segments pour l'animation. Aucun dialogue ni voix off.

```bash
cd facebook-coaching-ad
bun i
bun run build
bun run dev
bun run render
```

Sortie `out/FacebookCoachingAd.mp4`. GitHub Actions : `Render FacebookCoachingAd`, artifact `FacebookCoachingAd-MP4`.
