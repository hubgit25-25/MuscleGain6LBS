# Augmenter le pari — 3D

8 s, 1920x1080, 60fps, 480 frames. Real Three.js 3D trading room with rows of CRT-style terminals, physical desks, reflective materials, lighting, camera depth. Authentic Soros and Druckenmiller photographs loaded at render time. 3D-style counter from 0 to **≈ 10 000 000 000 $** with the exact label **Taille estimée de la position**. This is estimated position size, **not profit**.

The trading room is a procedural 3D reconstruction, **not a photorealistic generated scene**; the authentic portraits are not period-1992 photos. Portraits and their licensing attribution are sourced as documented in `soros-team-documentary/README.md`. If downloading a source fails, render must fail rather than silently substitute fake imagery.

Run `bun i && bun run build && bun run render`; MP4 artifact `IncreaseTheBet1992-MP4`.
