# Allemagne vs Royaume-Uni — 1992

8s, 1920x1080, 30fps, Remotion. Cinematic split-screen using **genuine archival photographs** (downloaded during GitHub Actions build), independent animated chart lines, opposing arrows, light and text. The charts are **schematic**, not historical market data. The UK image depicts an abandoned industrial building in Chelmsford, January 1990, not specifically a documented 1991–92 recession closure.
