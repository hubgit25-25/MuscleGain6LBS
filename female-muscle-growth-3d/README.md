# FemaleMuscleGrowth

Independent 5-second / 150-frame / 1080x1920 / 30fps anatomical 3D biceps growth animation. Procedural Three.js muscle with two heads, tendon, 44 curved fiber strands, deterministic volume growth, contraction, lighting, camera orbit and zoom. No humans, avatars, full bodies, text, dialogue or external media. Stylized anatomical visualization, not a clinically exact model; 5 seconds symbolically represent weeks/months of adaptation.

Run `bun i`, `bun run build`, `bun run render`. Output `out/FemaleMuscleGrowth.mp4`. GitHub artifact `FemaleMuscleGrowth-MP4`.
