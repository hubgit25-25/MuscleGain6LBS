# Weight195LBS

Vidéo motion design fitness verticale de **4 secondes**, 1080 × 1920, 30 FPS, 120 frames. Fond noir, lumière rouge, compteur 0 → 195, impact, apparition de **LBS**, particules, glow et zoom final. Sans voix ni dialogue.

Depuis ce dossier :

```bash
bun i
bun run build
bun run render
```

Résultat : `out/Weight195LBS.mp4` (H.264). La police utilise Montserrat si disponible, avec des polices grasses de remplacement. Le rendu GitHub Actions produit un artifact `Weight195LBS-MP4`.
