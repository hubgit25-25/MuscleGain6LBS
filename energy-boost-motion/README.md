# EnergyBoostMotion

Independent premium 5-second vertical 1080×1920 30fps Remotion animation. SVG battery charge from 10% to 100%, red-yellow-green gradient, electric arcs, shockwave, deterministic particles and final neon lightning with `PLUS D’ÉNERGIE`. No people, photos, voice or external media. Percentages are symbolic, not medical measurements.

Run `bun i`, `bun run build`, `bun run render`.

Output: `out/EnergyBoostMotion.mp4`; GitHub artifact: `EnergyBoostMotion-MP4`.
