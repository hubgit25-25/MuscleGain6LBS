# THE COST OF INTEREST RATES

8 seconds, 1920×1080, 60fps, 480 frames, H.264. Remotion documentary motion design. Scenes: shop, factory, brick house, rising cost of borrowing, gold/red financial effects, and animated gold balance comparing interest returns and currency risk.

**Visual fidelity:** The current committed environmental assets are original stylized SVG *placeholders*, not photorealistic reconstructions. Replace `public/environments/{shop,factory,house}.svg` with photorealistic period reconstructions (same filenames or update `src/scene.tsx`) for the approved visual quality. The project is otherwise self-contained and has no external asset dependencies.

No fabricated interest rates or FX data. Illustrative balance and arrows, not guaranteed returns.

Run `bun i`, `bun run build`, `bun run render`. Output `out/CostOfInterestRates.mp4`, artifact `CostOfInterestRates-MP4`.
