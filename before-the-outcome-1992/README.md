# Avant de connaître le résultat

8 s, 1920×1080, 60 FPS (480 frames), H.264 MP4. Procedural Three.js 3D trading room with a generic, anonymous trader silhouette viewed from behind and three CRT-style monitors. Three illustrative possible outcomes: **baisse de la livre**, **défense réussie**, **attente prolongée**. Mechanical clock and a nonnumeric financing-cost indicator. Ends with **L'ISSUE RESTE INCERTAINE**.

**Accuracy:** All trajectories are hypothetical and schematic; they are not historical exchange-rate quotes. Financing cost indicator has no invented amounts, rates or timestamps. The 3D trading room is stylized, not photorealistic. No actual historical person is depicted.

`bun i && bun run build && bun run render` outputs `out/BeforeTheOutcome1992.mp4`. GitHub Actions artifact `BeforeTheOutcome1992-MP4`.
