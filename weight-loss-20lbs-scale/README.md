# WeightLoss20LBS

Independent 5-second 1080x1920 30fps Remotion animation. Detailed CSS 3D digital glass scale, green activation sweep, animated floating 0 to -20 LBS (lost weight, not current scale reading), particles, glow and impact. No character, voice or subtitles.

Commands: bun i; bun run build; bun run render.

Output: out/WeightLoss20LBS.mp4. GitHub artifact: WeightLoss20LBS-MP4.
