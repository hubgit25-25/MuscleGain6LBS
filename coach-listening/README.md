# CoachListening

Vidéo Remotion purement visuelle : 5 s, 1080×1920, 30 FPS, 150 frames. Aucun dialogue, aucune voix off, aucun sous-titre, aucun audio. Sans média réel fourni, les personnages sont des SVG stylisés et ne sont pas présentés comme photoréalistes.

```bash
bun i
bun run build
bun run render
```

Sortie : `out/CoachListening.mp4`.
