# Les tensions européennes (1992)

**10 secondes · 1920×1080 · 60 FPS · 600 frames · MP4 H.264**.

Chronology: 7 February Maastricht treaty signed; 2 June Danish voters reject it; 17 September Italy suspends the lira's ERM participation; 20 September France narrowly approves the treaty. Source: EUR-Lex Decision 93/258/EEC, European Commission Maastricht audiovisual archives.

**Visual provenance:** Photographs are actual 1992 Maastricht treaty signatory images from Wikimedia Commons. The Danish, Italian and French photographs show national delegations **at the treaty signing**, not photographs of the later Danish vote, Italian ERM exit, or French vote. The event captions are historically grounded but must not be mistaken for image-specific captions. Verify each Wikimedia file license and attribution before external publication. The map uses Natural Earth geography from the geo-countries repository; 3D relief and highlights are constructed in Three.js. The map is stylized and simplified.

Build locally: `python3 -m pip install Pillow && python3 scripts/prepare_assets.py && bun i && bun run build && bun run render`. Github Actions artifact `EuropeanTensions1992-MP4`.
