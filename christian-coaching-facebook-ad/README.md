# ChristianCoachingFacebookAd

8 secondes, 1080×1920, 30 FPS, 240 frames. Publication Facebook sponsorisée simulée, avec cinq avantages, SVG animés, slogan et bouton CTA. Tous les textes de l'utilisateur sont préservés dans `src/copy.ts`. Aucune voix off ni dialogue. Le post est un mockup, pas une publicité Facebook réellement diffusée.

```bash
cd christian-coaching-facebook-ad
bun i
bun run build
bun run dev
bun run render
```

Export `out/ChristianCoachingFacebookAd.mp4`. GitHub Actions workflow `Render ChristianCoachingFacebookAd`, artifact `ChristianCoachingFacebookAd-MP4`.
